# QIDRA - вопросы по реализации расчёта распределений

Дата добавления: 2026-08-08  
Репозиторий: `qidra-platform`  
Связанные документы:

- `docs/qidra-project-transfer-dossier.md`
- `docs/qidra-former-team-questionnaire.md`
- `docs/qidra-production-verification-runbook.md`

Этот документ является отдельным техническим опросником по фактической реализации расчёта периодов, дивидендов и распределений в QIDRA. Его нужно использовать при передаче проекта новой команде и при независимой проверке финансового контура.

Критично: отвечать нужно по той ветке и тому commit, которые реально развёрнуты на production. Не отвечать по локальному коду, если он отличается от production.

## Как отвечать

Это важнее самих вопросов.

1. По каждому ответу указывать путь к файлу и номера строк.
2. Приводить фактический код, а не пересказ того, что он должен делать.
3. Если код и комментарий расходятся - сказать об этом прямо.
4. Не описывать замысел. Нужно поведение на сегодняшнем коде production.
5. Если чего-то нет - писать `не реализовано`. Это нормальный ответ и он ценнее догадки.
6. Указать, с какой ветки и какого commit сделан разбор.

## Блок 11. Контрольный расчёт

Это самый полезный пункт. Просьба выполнить и прислать результат.

Запустить текущий код расчёта на следующих данных и привести полученные суммы с точностью до копейки:

```text
Проект:
  сбор            01.03.2026 - 31.03.2026
  запуск          01.05.2026
  доля участников 70%
  период          01.05.2026 - 30.06.2026

Результат периода:
  валовая выручка         184 500.00
  прямые расходы          142 800.00
  операционные расходы      9 400.00

Участники:
  A  5 000  участие подтверждено 05.03.2026
  B  3 000  участие подтверждено 28.03.2026
  C  2 000  участие подтверждено 20.05.2026
```

Прислать:

1. Сумму на каждого участника, как её выдаёт текущий код.
2. Сумму всех выплат.
3. Количество дней, которое код засчитал каждому участнику.
4. Промежуточные значения: чистая прибыль, пул участников, веса.
5. Если код не принимает такие входные данные - объяснить, почему, и какие данные ему нужны.
